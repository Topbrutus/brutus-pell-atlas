# References and Antériorité

This atlas deliberately separates exact in-repository computation from literature claims.

External references for standard Pell/Lucas rank-of-apparition theory, prime-power lifting, Pell-Wieferich behavior, and related Diophantine work should be added with exact bibliographic metadata before any claim of novelty is made.

Current repository labels:

- `VERIFIED_COMPUTATION` — independently recomputed in this repository;
- `DERIVED_RELATION` — algebraic consequence of declared assumptions;
- `KNOWN_THEORY` — requires a bibliographic source;
- `RESEARCH_CANDIDATE` — open research object.

The antériorité review remains an explicit next-stage research task.
